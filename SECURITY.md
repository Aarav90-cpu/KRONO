## Reporting a Vulnerability

If you find any vulnerability DO NOT OPEN A PUBLIC ISSUE. Write to me at [aarav.kharade1234@gmail.com](mailto:aarav.kharade1234@gmail.com).

Structure of the Email:

```kotlin

[Vulnerability Description]

[Level: Its Small, Medium, or High]

[ Where the Vulnerability is? ]

[Your Name]
[Your Github Account Link] (optional)

```

By `[Your Github Account Link]` I mean https://github.com/<USERNAME>

E.g. Mine is Aarav90-cpu : https://github.com/Aarav90-cpu

We ask you this so that we can make sure you get the proper credits due. You can also remain anonymous.

## Offering a patch...

Create a Topic that says something that dosent scream "a vulnerability", and amongst the changes slide in a patch. Or write the code changes to me via mail on the address provided!

> Even though you wrote the code and sent it via email or opened a pull request to offer patch on github you have to email me everything as shown in the Structure of Email Above.
> If you don't you will not be credited for the patch only for the pull request

This will make sure the vulnerability does not go public creating a havoc.

The Email must have 0 attachements and must be fully text only! Even if it has it the attachements will be ignored!
